LESSON 19

Box model

Learn the fundamental concept of box model in CSS.

Video Lesson Beginner

About this lesson

Learn about the box model in CSS, which is a fundamental concept for understanding how elements are rendered on a webpage. The box model consists of margins, borders, padding, and the content area, and it affects the layout and spacing of elements. In this lesson, students will explore how to manipulate these properties to create visually appealing and well-structured web pages.

What you'll learn

  • Learn how HTML elements are structured as boxes in CSS.
  • Understand the area where an element’s actual text or content is displayed.
  • Learn how to create space between the content and the element’s border.
  • Learn how to add and style borders around elements.
  • Understand how to create space between an element and other elements on a webpage
