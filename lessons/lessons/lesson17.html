LESSON 17

CSS Backgrounds

Learn how to use CSS backgrounds to style your web pages.

Video Lesson Beginner

About this lesson

The CSS Backgrounds lesson teaches learners how to style the background of webpages and e lements using colors, images, positioning, sizing, and repetition. By the end of the lesson, they’ll be able to create visually appealing backgrounds and use CSS background properties effectively to improve the look and feel of a website.

What you'll learn

  • Set background colors for webpages and individual elements.
  • Add images as backgrounds to HTML elements.
  • Control how background images are sized and positioned.
  • Learn how to repeat, prevent repetition, or control image tiling.
  • Combine multiple background properties into a single CSS declaration.
